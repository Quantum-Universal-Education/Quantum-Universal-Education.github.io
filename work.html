Featured · 2026

qregime

An open-source decision layer that compares quantum error mitigation, partial quantum error correction, and full fault tolerance for a given circuit, hardware profile, reliability target, and physical-qubit budget.

  • OpenQASM 2 input and hardware profiles
  • Surface-code memory experiments with Stim and PyMatching
  • Resource estimates, validation tests, and documented limitations
  • Python
  • QEC
  • FTQC
  • Open source
