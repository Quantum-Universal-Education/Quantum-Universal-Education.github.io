qregime

QEM, QEC or FTQC? Before you run a quantum circuit, someone has to decide how errors will be handled. qregime makes that choice explicit: give it an OpenQASM 2 circuit and a hardware profile, and it returns the cheapest regime that meets your reliability target, or a quantified gap if none does.

Three regimes

The choice decides whether a circuit needs 16 physical qubits or 30,000.

QEM

Error mitigation

Run on raw physical qubits and correct the statistics afterward. Cheapest in qubits, limited by circuit depth and noise.

PARTIAL QEC

Small-distance codes

Encode with a surface code smaller than full fault tolerance needs. The best reliability reachable with the qubits you actually have.

FTQC

Full fault tolerance

Surface code plus magic-state factories, sized to the logical error budget. Cost reported in physical qubits and runtime.

Run the interactive notebook

The reproducible, hands-on entry point is the Jupyter tutorial. It explains the decision workflow step by step, lets you inspect the assumptions and parameters, and runs the example analysis in a hosted Python environment. You can also inspect every cell and its outputs on GitHub.

Engineering case study

From circuit requirements to an explicit error-handling decision

Problem & approach

qregime makes the error-handling choice explicit. It accepts an OpenQASM 2 circuit and a hardware profile, then compares error mitigation, partial surface-code QEC, and full fault tolerance against a reliability target and physical-qubit budget.

Evidence & validation

The project includes rotated surface-code memory experiments using Stim and PyMatching, resource estimates in physical qubits and runtime, and precomputed comparisons across example circuits and hardware profiles. The repository includes automated tests and an Apache 2.0 license.

Engineering surface

  • Command-line decision workflow
  • OpenQASM input and hardware profiles
  • Reliability target and resource-budget constraints
  • Colab tutorial and reproducible example outputs

Current limitation

The hosted interactive demo is not yet available. The current reproducible path is the local CLI and Colab tutorial; the results shown on this page are precomputed for the documented configurations.
