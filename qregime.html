qregime

QEM, QEC or FTQC? Before you run a quantum circuit, someone has to decide how errors will be handled. qregime makes that choice explicit: give it an OpenQASM 2 circuit and a hardware profile, and it returns the cheapest regime that meets your reliability target, or a quantified gap if none does.

Build a circuit GitHub ↗ Open tutorial in Colab ↗

Three regimes

The choice decides whether a circuit needs 16 physical qubits or 30,000.

QEM

Error mitigation

Run on raw physical qubits and correct the statistics afterward. Cheapest in qubits, limited by circuit depth and noise.

PARTIAL QEC

Small-distance codes

Encode with a surface code smaller than full fault tolerance needs. The best reliability reachable with the qubits you actually have.

FTQC

Full fault tolerance

Surface code plus magic-state factories, sized to the logical error budget. Cost reported in physical qubits and runtime.

Live demo

The hosted demo is coming soon. Meanwhile, build a circuit in the Quantum Circuit Playground, export its OpenQASM, and run qregime locally or in the Colab tutorial ↗.

pip install git+https://github.com/MaldoAlberto/qregime.git
qregime decide circuit.qasm --hardware trapped_ion_quantinuum_h2 --budget 5000

Results on example circuits
