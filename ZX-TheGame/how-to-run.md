## 🎮 Running the ZX-Pygame Version

You can run the **Pygame-based ZX diagram game** directly from your terminal or command prompt. Follow these steps:

---

### 1️⃣ Install Required Libraries

Before running the game, ensure that the required Python libraries are installed. Use pip to install them:

```bash
pip install pygame pyzx numpy
```
## Navigate to the Game Directory
Open your terminal or command prompt and change the directory to your main project folder — ZX-TheGame:
```
cd path/to/your/ZX-TheGame

```
